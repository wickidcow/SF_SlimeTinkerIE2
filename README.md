## 🔨 What does SlimeTinker do?

SlimeTinker recreates a **customizable tool-building progression** inside Slimefun. Players create tools from supported materials, improve them through use and leveling, and apply modifiers through SlimeTinker's workstations and systems.

This maintenance branch keeps:

- original SlimeTinker items, recipes, workstations, and English lore;
- customizable tool/material progression;
- leveling and modifier systems;
- **Infinity Expansion 2** material support using current IE2 item IDs;
- **DynaTech** material support;
- existing integrations for compatible addons such as SlimefunWarfare, LiteXpansion, TranscEndence, and Networks where the installed versions expose the expected APIs.

Do not install obsolete Infinity Expansion v1 beside Infinity Expansion 2 solely for this fork; the maintained integration path targets IE2.

## 🧪 Slimefun Legacy maintenance

Slimefun Legacy is the primary presentation and maintenance target for this repository. Compatibility code inherited from later community forks may also recognize related Slimefun API implementations, but that does not make those forks the branding or primary runtime target of this project.

Exact optional-addon requirements depend on the integrations you want to use. Review the current `plugin.yml`, build file, and startup log when deploying.
